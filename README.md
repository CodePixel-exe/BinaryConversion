# Conversion App
A JavaFX app that has the ability to do conversions for binary to decimal, Bitwise logic operators, ASCII character conversion and features an AI chatbot.

# Features
## Binary Conversion
This application can convert decimal to binary and vice-versa but can also convert the following:
-Decimal to Hexadecimal
-Hexadecimal to Decimal
-Hexadecimal to Binary
-Binary to HexaDecimal

## Bitwise logic
The application also features a bitwise logic section where you can apply operators to binary numbers such as:
-OR
-XOR
-AND

## ASCII Conversion
The BinaryConversion App also features a section to allow for ASCII character conversion to hexadecimal values or decimal values.
